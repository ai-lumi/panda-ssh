# ssh-content-page Specification

## Purpose

为 SSH 终端标签提供跨阶段且稳定的内容区呈现，使状态变化和工作区尺寸变化不损害终端会话或内容层级。

## Requirements

### Requirement: SSH 内容页在整个会话生命周期保持稳定画布

SSH 终端标签 SHALL 在连接中、已连接和失败/断开阶段始终占用完整的 detail 内容区。阶段指示 MUST 属于内容画布，MUST NOT 进入工作区顶部 chrome 或详情底边，并且不得额外建立工具栏行。

#### Scenario: 连接建立中

- **WHEN** 已通过凭据与主机密钥门控但 shell 尚未建立
- **THEN** 内容画布在可用区域居中显示连接状态和非敏感主机标识，且剩余区域保持终端画布背景

#### Scenario: 已连接

- **WHEN** shell 已建立
- **THEN** 终端视图独占内容画布并获得键盘输入能力

#### Scenario: 连接失败或断开

- **WHEN** 认证、传输或远端 shell 结束导致会话失败
- **THEN** 内容画布居中显示可区分的失败摘要、重试与关闭操作，且不得影响其它标签页

### Requirement: SSH 内容页对工作区尺寸变化保持会话连续

窗口缩放、全屏切换和侧栏显示/隐藏 SHALL 仅改变 SSH 内容页的可用尺寸。已建立 shell MUST 接收正确的终端尺寸更新；连接中或失败态 MUST 保持居中并不得重建会话或重启连接。

#### Scenario: 调整窗口或侧栏

- **GIVEN** 一个连接中、已连接或失败的 SSH 终端标签
- **WHEN** 用户缩放窗口、切换全屏或隐藏/恢复侧栏
- **THEN** 内容页在新的可用矩形中正确布局；仅已连接终端按既有规则更新 PTY 尺寸
