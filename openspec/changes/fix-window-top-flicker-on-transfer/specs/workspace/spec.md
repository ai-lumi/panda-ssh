# workspace Delta

## ADDED Requirements

### Requirement: 主窗口 chrome 配置幂等

macOS 主窗口的窗口级 chrome 属性（标题栏样式、红绿灯按钮状态、分栏位置）SHALL 仅在其有效输入（窗口尺寸、全屏状态、侧栏可见性与宽度）发生变化时重新配置。窗口几何度量（标题栏安全区宽度、侧栏宽度）在数值未变化时 MUST NOT 发布变更通知；同一输入下的重复配置 MUST NOT 产生可观察的视觉变化或新的渲染循环。

#### Scenario: 窗口静止时无重复配置

- **GIVEN** 窗口尺寸、侧栏宽度与全屏状态均未变化
- **WHEN** 应用内其他视图因任意原因发生 SwiftUI 更新
- **THEN** 窗口 chrome 属性不被重新写入导致视觉变化，且不引发额外的自发性渲染循环

#### Scenario: 几何度量重复上报被去重

- **WHEN** 相同的标题栏安全区宽度或侧栏宽度被重复测量并上报
- **THEN** 不产生重复的变更通知，订阅该度量的视图不失效

#### Scenario: 分栏位置设置幂等

- **GIVEN** 侧栏处于可见状态
- **WHEN** 分栏策略计算出的目标侧栏宽度与当前实际宽度差值可忽略（不超过 0.5pt）
- **THEN** 不强制重新设置分栏位置，分栏不发生抖动

#### Scenario: 有效输入变化时正常跟随

- **WHEN** 用户拖动窗口边缘 resize、进出全屏或拖动分栏分隔条
- **THEN** 标题栏安全区、红绿灯按钮呈现与分栏位置正确跟随更新，行为与修复前一致

#### Scenario: 无传输任务空转时低开销

- **GIVEN** 应用空闲且没有任何进行中的传输任务
- **WHEN** 主窗口保持打开且不被交互
- **THEN** 主窗口不因 chrome 度量自激励而持续重绘，空闲 CPU 占用不因渲染循环升高
