# inspection-reporting 规格（增量）

## Purpose

定义巡检结果的应用内报告与离线 HTML 导出（路线图 8.7 决策 3、14.8 HTML 模板）：应用内报告为首版必含；HTML 导出作为本提案内后续任务组，须遵守远端文本按不可信数据做上下文正确转义、单文件不加载外部资源、失败与缺段可见的边界。

## ADDED Requirements

### Requirement: 应用内报告

每次巡检运行 SHALL 提供应用内报告，按主机分组展示：指标值与单位、采集时刻与采样窗口、质量状态、阈值评估结果与触发原因、解析错误、输出截断标记与审计缺段。报告 MUST 将失败、未知与过期项同有效项区分展示，MUST NOT 制造完整或全部正常的假象。

#### Scenario: 报告按主机展示完整上下文

- **GIVEN** 一次巡检运行完成
- **WHEN** 用户打开该运行的应用内报告
- **THEN** 报告按主机分组展示各指标值、单位、采集时刻、质量状态与阈值结论，失败与过期项在独立类别可见

### Requirement: 离线 HTML 导出边界

HTML 导出（本提案内后续任务组启用）SHALL 产出单文件离线报告：MUST NOT 引用或加载任何外部资源；所有来自远端的文本 MUST 按不可信数据处理，在 HTML、属性、URL 与脚本数据等上下文中做上下文正确转义，嵌入脚本的数据 MUST NOT 仅依赖 HTML autoescape；导出前 MUST 向用户展示导出范围（运行、主机与指标集合），导出行为 MUST NOT 向远端或第三方发送数据。

#### Scenario: 远端输出含元字符

- **GIVEN** 某主机命令输出包含 HTML 与引号元字符
- **WHEN** 用户导出 HTML 报告
- **THEN** 导出文件中该内容按所在上下文正确转义，浏览器打开时显示为文本而非被解释为标记或脚本

#### Scenario: 导出文件离线可用

- **GIVEN** 用户导出一份 HTML 报告
- **WHEN** 在断网环境打开该文件
- **THEN** 报告完整渲染，MUST NOT 请求任何外部资源

#### Scenario: 导出范围明示

- **GIVEN** 用户选择导出某次运行
- **WHEN** 系统生成 HTML 文件
- **THEN** 导出前展示该文件包含的运行、主机与指标范围，且导出过程不产生对远端主机的任何请求

### Requirement: 模板只读与缺段展示

内置报告模板 SHALL 为只读；用户 SHALL 能保存模板副本并编辑，副本 MUST 记录来源模板版本。报告与导出 MUST 展示采集失败、数据过期与证据缺失（审计缺段）；模板渲染失败时系统 SHALL 回退输出纯文本摘要，MUST NOT 在不加标注的情况下输出可能不完整的正式报告。

#### Scenario: 模板渲染失败回退

- **GIVEN** 用户使用编辑过的模板副本且其中存在渲染错误
- **WHEN** 用户生成报告
- **THEN** 系统回退为纯文本摘要并提示模板渲染失败，MUST NOT 静默输出不完整的正式报告
