> 约定：测试任务先于实现任务（TDD red-green-refactor），每个任务为一次可验证提交；测试任务须覆盖正常流程、意外操作、边界条件三类场景。依赖：授权提案（计划结构与强制检查契约）、审计提案（记录与阻断契约）并行评审中， trait 端口以共享契约为准（见 design D1/D9）。
