## Context

见 proposal.md。当前 `TerminalTabView` 仅在 shell 阶段挂载终端模拟器；连接中、结束和失败均以其他 SwiftUI 内容替代它，因此替换会销毁终端组件持有的 scrollback。当前终端协调器还须在终态明确停止读写，不能依赖视图被移除来阻断输入。

## Goals / Non-Goals

**Goals:**

- 使一个 SSH 页签在门控完成后的整个会话生命周期复用同一终端模拟器实例。
- 使 SSH 与 SFTP 都只保留一个可见的重新连接入口：页签操作。
- 在不显示不安全原始错误文本的前提下，保留断连前的用户上下文。

**Non-Goals:**

- 不保持旧 SSH channel 或失效 SFTP 句柄可用；重连始终建立新的会话代次。
- 不把仅用于连接过程的状态信息伪装成远端 shell 输出。

## Decisions

### 1. SSH 使用常驻终端模拟器与本地状态提示

凭据与主机密钥门控通过后，页签立即挂载终端模拟器，即使尚无 `ShellConnection`。连接中、本地连接失败、正常 shell 结束及异常断开都以终端画布内的本地状态提示呈现；已连接后再把新连接绑定到同一模拟器并启动读循环。

这避免状态分支替换并销毁 scrollback，也让连接提示复用终端框架。替代方案是独立状态页或在断开后重建终端模拟器；两者都会破坏用户已见输出，故不采用。

### 2. 终态只读，重连只在页签操作

终态到达时停止读循环，释放旧句柄，并将终端输入、粘贴、清屏和其它写入型动作置为不可用；复制、选择与滚动保持可用。终端画布仅显示安全白名单投影的本地终态提示，不放置重新连接按钮。

SSH 与 SFTP 的页签操作是唯一触发 `retry` / 新连接代次的入口。内容区不再重复提供相同操作，以避免状态、并发保护和可发现性在多个入口漂移。

### 3. SFTP 断连保留快照但不伪装为在线

SFTP 成功读取初始远程目录后，若会话级 Transport 或句柄确认不可用，则保留已提交的本地/远程目录快照、路径及选择状态，标记页签失败；远程导航、刷新、创建、删除、冲突检查和新传输在调用 FFI 前统一拒绝。内容区显示非阻塞的只读断连提示，但不提供重新连接按钮。

权限拒绝、路径不存在、覆盖冲突和单项传输失败仍走原有业务错误路径；不得以错误字符串猜测会话断开。必要的判定收敛在 core/FFI 的结构化边界。

## Risks / Trade-offs

- [Risk] 常驻终端在未连接时的尺寸或焦点回调可能误触发远端操作。→ 仅在会话可交互时上报尺寸和请求输入焦点。
- [Risk] 旧连接迟到的读写回调影响已重连会话。→ 保持代次校验与连接身份校验，终态和重连必须拒绝旧代次回调。
- [Risk] 保留的 SFTP 快照可能过时。→ 明确标为断开前快照，远程操作不尝试执行，重连成功后再刷新。
- [Risk] 页签操作在小尺寸下不明显。→ 复用并验证现有页签操作在 macOS 与 iPadOS 的可访问路径；不另设内容区备份入口。
