## MODIFIED Requirements

### Requirement: SSH 内容页在整个会话生命周期保持稳定画布

SSH 终端标签 SHALL 在连接中、已连接和已建立后的结束/断开阶段始终占用完整的 detail 内容区。阶段指示 MUST 属于内容画布，MUST NOT 进入工作区顶部 chrome 或详情底边，并且不得额外建立工具栏行。

初次连接失败时，内容画布 MAY 居中显示可区分的失败摘要、重试与关闭操作。已建立 shell 后正常或异常结束时，内容画布 MUST 保留已经接收的终端内容与滚动上下文，MUST NOT 用居中错误页替换该内容；终端输入 MUST 立即不可用，并在不遮挡历史内容的前提下显示安全终态原因及手动重新连接入口。原因 MUST 来自白名单结构化终态，MUST NOT 直接显示任意远端文本、终端输出、命令、凭据或 panic 载荷。

#### Scenario: 连接建立中

- **WHEN** 已通过凭据与主机密钥门控但 shell 尚未建立
- **THEN** 内容画布在可用区域居中显示连接状态和非敏感主机标识，且剩余区域保持终端画布背景

#### Scenario: 已连接

- **WHEN** shell 已建立
- **THEN** 终端视图独占内容画布并获得键盘输入能力

#### Scenario: 初次连接失败

- **WHEN** 认证或传输失败，且 shell 尚未建立
- **THEN** 内容画布居中显示可区分的失败摘要、重试与关闭操作，且不得影响其它标签页

#### Scenario: 已建立后发生异常断开

- **GIVEN** shell 已建立并已显示终端输出
- **WHEN** 发生已确认的读写、keepalive、Transport 或协议故障
- **THEN** 已显示的输出和滚动上下文保持可见，输入不可用
- **AND** 画布显示安全的故障类别及可用数值码和重新连接入口，且不显示任意原始异常文本
