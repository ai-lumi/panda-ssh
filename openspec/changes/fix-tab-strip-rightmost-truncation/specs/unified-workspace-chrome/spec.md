# unified-workspace-chrome Delta

## ADDED Requirements

### Requirement: 最右侧页签完整显露

当工作区页签总宽度超过可见宽度时，页签容器 SHALL 保证用户可通过滚动、浏览控件或选择页签将最右侧页签的完整内容显露在可见区内。最右侧页签的关闭按钮与全部文本 MUST NOT 被容器边界或浏览控件截断。

#### Scenario: 滚动到最右侧页签

- **GIVEN** 工作区存在多个页签且总宽度超过可见宽度
- **WHEN** 用户点击右侧浏览按钮、滚动鼠标滚轮或选择最右侧页签
- **THEN** 容器 SHALL 将最右侧页签的完整内容（含关闭按钮）显露在可见区内，且不得越过内容边界产生空白超滚

#### Scenario: 浏览按钮出现导致可视区变窄

- **GIVEN** 页签内容原本接近可视区右边界
- **WHEN** 右侧浏览按钮出现并占据可视空间
- **THEN** 容器 SHALL 重新计算滚动边界，用户仍可将最右侧页签完整显露
