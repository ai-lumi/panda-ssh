## Purpose

允许用户配置 SSH 终端的回滚缓冲区大小（以行数为单位），平衡历史回溯能力与内存占用。配置校验由 Rust 提供，Swift 经 FFI 调用，遵循平台分层约束。

## ADDED Requirements

### Requirement: 缓冲区行数配置

系统 SHALL 提供全局设置项「终端缓冲区行数」，允许用户输入最大保留行数。默认值 MUST 为 10000 行，最小允许值 MUST 为 1000 行，最大允许值 MUST 为 100000 行。设置变更后 MUST 持久化保存。配置校验 MUST 由 Rust 在 `crates/panda-core/src/config.rs` 提供：Rust SHALL 负责默认值、原始文本解析及范围检查，并经 FFI 返回规范化整数或可区分错误；Swift MUST 将未解析的表单文本及 `UserDefaults` 原始值交由 FFI，不在 Swift 侧重复解析、夹限或决定默认值，且只持久化 FFI 返回的规范化整数。

#### Scenario: 用户修改缓冲区行数

- **WHEN** 用户在设置页将缓冲区行数从 10000 改为 50000
- **THEN** 输入经 Rust 校验通过后保存，新打开的终端标签页使用 50000 行缓冲区

#### Scenario: 输入超出范围被阻止

- **WHEN** 用户输入 500 或 200000
- **THEN** Rust 校验返回错误，系统提示「请输入 1000–100000 之间的数值」，不保存非法值

#### Scenario: UserDefaults 原始值损坏

- **GIVEN** `UserDefaults` 缺失值或存储了非法原始值
- **WHEN** Swift 请求终端初始化配置
- **THEN** Swift 将该原始值交给 Rust FFI，Rust 返回默认值 10000 或可区分的校验结果
- **AND** Swift 不在本地实施范围判断或默认值规则

#### Scenario: 默认值

- **GIVEN** 用户从未修改过缓冲区行数设置
- **WHEN** 打开新终端标签页
- **THEN** 该终端使用默认值 10000 行缓冲区

### Requirement: 仅新标签生效

缓冲区行数配置变更后，仅对新打开的终端标签页生效。已打开的终端标签页 MUST 保持其创建时的缓冲区大小，避免运行时截断用户正在查看的内容。

#### Scenario: 已打开终端不受配置变更影响

- **GIVEN** 用户已打开一个终端标签页（缓冲区 10000 行）
- **WHEN** 用户将设置改为 5000 行并打开新标签
- **THEN** 旧标签页仍保留 10000 行缓冲区，新标签页使用 5000 行

#### Scenario: 配置快照在终端初始化时确定

- **GIVEN** 用户在设置中将缓冲区行数设为 25000
- **WHEN** 打开新的终端标签页
- **THEN** 该终端在首批输出前读取并应用 25000 行配置快照
- **AND** 后续配置变更不影响此已打开终端

#### Scenario: 重连和页面切换不覆盖旧快照

- **GIVEN** 终端已使用特定缓冲区大小初始化
- **WHEN** 用户重连同一标签、切换页面或 SwiftUI 重建视图
- **THEN** 终端保持原初始化时的缓冲区大小，不偷偷读新配置

### Requirement: 终端缓冲区设置表单

设置界面 MUST NOT 显示内存估算。回滚行数 MUST 使用平台原生整数输入控件，而非自由文本输入；范围判断、默认值和非法值处理仍 MUST 由 Rust FFI 提供。范围与生效范围 MUST 仅作为一条辅助说明显示为「范围 1000–100000；仅对新打开的终端标签生效。」；输入控件内或旁边 MUST NOT 重复显示范围提示。显式保存操作 MUST 位于该表单分区末端操作区，并在左至右阅读方向上视觉右对齐。

#### Scenario: 设置页以数字控件展示单一提示

- **WHEN** 用户打开终端设置
- **THEN** 显示可编辑的整数输入控件和一条「范围 1000–100000；仅对新打开的终端标签生效。」辅助说明
- **AND** 不显示内存估算、第二处范围提示或换行截断的范围标签

#### Scenario: 数字输入仍经统一校验

- **WHEN** 用户通过键盘、粘贴或辅助技术提交非整数或超出范围的值
- **THEN** 系统依照 Rust FFI 的校验结果拒绝该值且不保存

#### Scenario: 保存操作可在固定位置发现

- **WHEN** 用户完成有效回滚行数的编辑
- **THEN** 保存操作位于缓冲区表单分区的末端操作区，并在左至右阅读方向上视觉右对齐

### Requirement: 持久化使用 UserDefaults

缓冲区行数配置 SHALL 使用 `UserDefaults` 持久化，非敏感配置无需钥匙串保护。macOS 与 iPadOS 使用同一持久化机制，不要求 iCloud 同步。Swift 仅将 Rust FFI 已验证的规范化整数写入该存储；读取时不得绕过 Rust 校验。

#### Scenario: 重启后配置保留

- **GIVEN** 用户将缓冲区行数设为 30000
- **WHEN** 应用重启
- **THEN** 设置页显示 30000，新终端使用 30000 行缓冲区

#### Scenario: 无效配置回退默认值

- **GIVEN** UserDefaults 中存储了非法值（如 -1 或 999999）
- **WHEN** 读取配置
- **THEN** Rust 校验失败，回退使用默认值 10000
