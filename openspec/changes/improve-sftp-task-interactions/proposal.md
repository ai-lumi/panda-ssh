## Why

SFTP 删除深层目录时没有进度反馈，本地同步删除还可能阻塞主线程。后台删除需要与传输共享任务入口；右键选区的更新时机也未满足现有 workspace 规格。

## What Changes

- 删除经确认后创建任务，默认显示阻塞当前窗口交互的进度弹窗，提供「放入后台」；执行本身不阻塞主线程。
- 扫描阶段显示不定进度和已发现项数，删除阶段显示已处理/总项数、当前路径与失败信息。
- 「传输任务」入口和页面统一改称「任务」，类型区分上传、下载、本地删除、远端删除。
- 右键菜单显示前更新选区：集合内保留全部选中，集合外替换为目标单选；取消菜单仍保留此次选择。
- macOS 增加退出保护：无未完成任务时首次 Command+Q 显示悬浮提示，3 秒内再次独立按下才退出；有未完成任务时优先提示审查任务，重复快捷键不能绕过。

## Capabilities

### New Capabilities

- `sftp-delete-tasks`: 本地/远端删除任务、进度、前后台展示和生命周期。
- `quit-protection`: macOS 二次退出与未完成任务审查。

### Modified Capabilities

- `transfers`: 统一任务入口与类型化展示，保留已有传输操作。

右键选择属于恢复 `workspace` 现有「SFTP 文件行上下文菜单」需求，不新增重复规格。

## Impact

- Rust 删除遍历与任务管理、同步 FFI 接口和生成绑定。
- Swift bridge、任务源/队列、SFTP 会话/菜单、进度弹窗、任务页与侧栏。
- App 级退出入口、悬浮提示和任务审查导航；未完成批量操作即使仍在准备阶段也纳入退出保护。
- macOS 右键与 iPadOS 长按共用选择规则；双端均支持前后台删除和统一任务页。
- 新增 Rust fake 文件系统测试、Swift 状态与选择测试，回归双端构建与传输功能。

## Non-goals

- 不新增通用作业调度框架、第三方依赖或跨 App 重启的任务恢复。
- 不拦截系统强制结束进程，不承诺 iPadOS 系统结束 App 时能够弹出退出确认。
- 不改变传输暂停、重试、任务组和并发规则；不为删除添加暂停或自动重试。
- 不执行真实用户文件删除，不触碰当前已有暂存改动。
