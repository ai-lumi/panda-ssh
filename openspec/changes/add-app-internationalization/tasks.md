- [ ] 12.2 在受控测试会话中验证切换期间 SSH/SFTP、传输、未提交编辑不受影响；远端返回、用户输入、异常原文和底层依赖错误均未被翻译，程序说明使用当前语言。
- [ ] 12.3 检查英语长文案在 macOS 设置窗口、窄侧栏及 iPad 横竖屏下不遮挡重要操作/警告；发现问题先补复现或布局验证用例，再调整，不改变既有业务交互语义。
- [ ] 12.4 核对提案任务、资源清单、覆盖率与双端验证证据，全部完成后同步规范增量并归档；未满足双语完整性时不发布完成版本。
- [ ] 12.5 为 macOS 与 iPadOS 的中文、英语、跟随系统和无匹配回退验收保存可复现检查表及截图引用；截图应覆盖至少一个多窗口切换、一个安全提示和一个活动会话状态保护场景。
