# SFTP 与全局传输页面重构

## Why

SFTP 页签下方重复展示标题工具栏，占用文件浏览空间；地址栏图标、刷新和选择按钮存在 I 形光标反馈问题。传输数据已经全局共享，入口却依附 SFTP 侧滑面板，不利于跨主机查看任务。

## What Changes

- 移除页签栏与 SFTP 地址栏之间的标题及传输工具栏。
- 修正地址栏图标和按钮的指针反馈，输入文字区域保留文本光标。
- 在主窗口左下角、连接监控附近新增全局「传输任务」入口并显示活动任务数，参照连接监控：macOS 使用可复用独立窗口，iPadOS 使用独立工作区页面。
- 移除左下角预留的「代码片段」按钮，暂不开发代码片段功能；本次不涉及已有片段数据的删除。
- 移除 SFTP 内的传输侧滑面板、inspector 和 sheet，入队后保留提示，不自动切换页面。
- 每个任务展示源端、目标端、源路径、目标路径、实时速度、进度及状态，保留任务组和原有控制操作。

## Capabilities

### Modified Capabilities
- `workspace`：SFTP 内容布局、指针反馈、全局任务入口与任务组呈现。
- `transfers`：统一任务列表的字段与全局可达性。

## Impact

涉及 SwiftUI 工作区路由、窗口装配、SftpTabView、TransferPanelView 及呈现测试。复用现有 TransferStore、速度与进度数据，不改变 Rust 调度、凭据和连接生命周期。现有未提交的工作区改动必须保留。

## 评审状态

用户已于 2026-09-08 明确批准实施。

## 已批准的追加调整

用户要求移除本地地址栏右侧的重复上传按钮，保留底部上传按钮；本次仅精简 UI 入口。
