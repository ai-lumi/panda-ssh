## 1. 任务组数据模型

### 测试

- [x] 1.1 编写 `TransferTask` / `TransferRecord` 任务组字段测试：
  - 正常流程：带 `groupID`/`groupName` 的任务能被正确创建与比较。
  - 意外操作：`groupID` 为 `nil` 的任务不与其他任务同组。
  - 边界条件：同一组内多个任务共享同一 `groupID`。
- [x] 1.2 编写 `TransferStore` 任务组聚合测试：
  - 正常流程：多个同组任务能按组聚合展示。
  - 意外操作：无组任务与有组任务混合时正确区分。
  - 边界条件：空组（无任务）不展示。

### 实现

- [x] 1.3 在 `TransferTask` / `TransferRecord` 中新增 `groupID` 与 `groupName` 字段。
- [x] 1.4 在 `TransferStore` 中实现按 `groupID` 聚合的任务组视图，支持展开/折叠。
- [x] 1.5 实现任务组级批量控制：停止全部、重试全部（作用于组内所有任务）。

## 2. 本地文件栏多选与目录任务组

### 测试

- [x] 2.1 编写本地栏多选测试：
  - 正常流程：同时选中本地文件与目录后，目录生成任务组、文件生成独立任务。
  - 意外操作：未选中任何项目时点击上传不创建任务。
  - 边界条件：仅选中空目录时仍能生成任务组（可能为空组或仅目录结构）。
- [x] 2.2 编写本地栏进入目录与选中目录区分测试：
  - 正常流程：单击目录名进入目录，不触发传输。
  - 意外操作：多选模式下勾选目录再点击上传，不进入目录而生成任务组。
  - 边界条件：单选文件时仍走单文件传输流程。
- [x] 2.3 编写多选纯文件测试：
  - 正常流程：同时选中多个文件，每个文件生成独立任务，不生成任务组。
  - 边界条件：选中单个文件生成单个独立任务。

### 实现

- [x] 2.4 在 `FilePaneNavigator` / `SftpSessionStore` 中新增本地多选集合 `selectedLocalItems`。
- [x] 2.5 修改 `SftpTabView` 本地栏，进入多选模式后显示复选框，支持文件与目录同时勾选。
- [x] 2.6 实现本地目录预扫描：调用 Rust FFI 扫描目录内容，为每个文件创建带 `groupID` 的单文件任务。
- [x] 2.7 修改本地栏上传按钮逻辑：多选含目录时生成任务组，仅多选文件时生成独立任务，单选文件时走单文件上传。
- [x] 2.8 保持单击/双击目录进入目录的交互。
