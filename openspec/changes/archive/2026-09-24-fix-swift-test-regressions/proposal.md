## Why

连接监控改造的全量 Swift 门禁暴露了本地化空参数崩溃、窗口拖动旧断言及多个 UI 用例异常退出。用户要求列清单并修复，Linux 检查暂时跳过。

## What Changes

- 用现有失败用例和新增边界回归测试先记录 Red，再修复根因。
- 保持消息降级、窗口拖动、页签和传输展示的既有契约；校正与当前规格不一致的旧测试。
- 恢复应用停机时的 Swift 会话释放与标签关闭通知，复用既有单标签关闭适配，不改变核心停机规则。
- 修正导航测试的异步断言时序；补齐 FFI 假服务测试的主机信任前置条件、精确错误断言、远端删除与代次跟踪会话用例，不修改产品逻辑或覆盖率门禁。
- 修复日志后台刷新乱序：将快照读取、映射及发布整体串行到主线程，保留 Rust 同步写入与日志规则；补主线程发布、并发缓存一致性和清空后迟到刷新测试。
- 补齐私有批量执行器失败契约测试，提取重复的失败结果转换；保留所有错误分支、错误文本、关闭行为和 FFI API，不降低门禁。
- 串行运行 macOS / iPadOS 全量 Swift 测试，复验 Rust 全量及包级、逐文件覆盖率，记录失败清单、原因和验证结果。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

无规范级行为变更；本变更恢复既定契约，使用 `skip_specs: true`。本地化契约参照进行中的 `add-app-internationalization`，显式拖窗契约参照 `fix-macos-tab-drag-and-titlebar-zoom` 与当前工作区规格，不归档其他进行中变更。

## Impact

影响 Swift 本地化解析器、工作区停机会话适配及 macOS 窗口、页签、传输面板测试。消息解析器和停机适配为 macOS / iPadOS 共用；原生窗口问题仅影响 macOS。保持 Rust / FFI API、日志缓冲和持久化规则。

## Non-goals

不扩展日志架构，不变更连接监控事件契约，不执行 Linux 检查，不发布或提交。
