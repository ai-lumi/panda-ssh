## Context

参见 proposal.md。首轮日志确认空描述符在 `1..<0` 构造处崩溃；拖窗生命周期测试仍期待已禁用的隐式拖窗属性。其余异常退出需独立复现，不根据未完成记录推断根因。

依赖路径：`MessageDescriptor → LocalizedTextResolver → 中英消息资源 → UI`；`MainWindowChrome → NSWindow / NSHostingView → 原生拖动与宿主生命周期`；`WorkspaceStore / TransferStore → SwiftUI 展示测试`。

## Goals / Non-Goals

**Goals:** 保持合法参数排序、类型、数量校验和未知消息降级；恢复原生宿主生命周期稳定性，确保测试验证当前拖窗契约。

**Non-Goals:** 不调整消息、日志或传输业务规则，不新增依赖，不修改其他活动提案。

## Decisions

- 空数组按合法的零参数输入处理：遍历真实存在的相邻索引，不构造无效范围。比单独隐藏未知消息错误更完整，覆盖已知无参模板和缺参模板。
- 先定向复现异常退出，结合结果包定位 AppKit 生命周期问题；只有有失败证据才修对应实现或夹具。
- 拖窗属性断言依据已实现的显式 `performDrag` 契约校正；继续保留单击拖动、双击缩放和控件隔离用例，不回退产品行为以迎合旧断言。
- 崩溃栈与实际类型确认：SwiftUI 挂载会将宿主变成 `NSKVONotifying_*`，在其上继续替换 isa 会破坏 Foundation 动态属性查找；仅按父类缓存仍不足。删除运行时替换，使用公开 `NSWindow.isMovableByWindowBackground = false` 禁止隐式背景拖窗，显式 `performDrag` 与双击缩放保留。回归测试要求宿主类型不变并能替换、布局、更新。
- 页签及传输测试崩溃栈为 `_NSWindowTransformAnimation dealloc → objc_release`：测试夹具显式持有窗口并禁用 `isReleasedWhenClosed`，由 ARC 管理生命周期，不削弱渲染断言。
- 标题栏生命周期用例定向运行通过、批量运行在固定 50ms 窗口内失败，记录显示配置由异步挂载完成。测试改为有上限地等待实际透明状态，继续保留更新及拆卸后的原断言，不增加产品轮询。
- 日志缓冲测试耗时约 62 秒，不把慢测试当失败。后续全量及十轮定向运行确认并发发布竞态（十轮五失败）：后台线程先读的旧快照可能晚于新快照发布。先补主线程发布及 Rust/Swift 缓存一致性断言，再将读取、映射、发布整体串行到主线程；主线程调用继续同步刷新，后台调用不等待主线程，保留 1Hz 捕获 Rust 直接写入的定时器及所有日志业务规则。
- 全量测试确认应用停机仅同步核心空列表，遗漏 Swift 会话释放和关闭通知。先保存操作前标签标识，再复用 `syncAndReleaseSessions`；保留核心拒绝新工作的行为，并测试重复停机不重复通知，不增加新的业务规则。
- iPad 导航测试先于主队列中的切页更新断言；复用已有队列等待方法，保持原断言及产品异步更新契约。
- FFI 首批补测集中在 `ffi_fake_server.rs`：批量失败测试先强化错误断言记录失败，再补假服务器信任前置条件；远端删除和 tracked 会话通过现有回环假服务覆盖成功、失败及边界。以合并实例后的覆盖率计数确定缺口，不为达标删除代码、降低门禁或新增产品测试接口。
- batch 剩余错误适配在 `src/tests/batch_transfer_tests.rs` 中直接测试私有执行器，避免公共入口两次读取之间的人为竞态；共用失败结果转换保留全部分支、原错误文本、空 completed/skipped、cancelled=false 及既有关闭顺序。测试先固定契约，再最小重构；不通过污染共享 store 或删除回退分支提高覆盖率。

## Risks / Trade-offs

- [窗口退出可能由夹具或实现造成] → 用定向测试和崩溃栈确认，避免删除断言掩盖问题。
- [全量测试共享全局 Rust 服务] → 双平台串行执行，保持既有 reset 隔离。
- [本地化与拖窗规格仍在其他活动变更中] → 只恢复既定契约；不抢先归档这些变更。
