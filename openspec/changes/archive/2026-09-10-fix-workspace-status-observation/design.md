## Context

终端连接阶段变化和读循环结束均调用 `reportConnectionStatus`。页签栏与侧栏通过 `@EnvironmentObject` 观察工作区，但其状态查询直接读取 Rust，并未经过 `@Published` 属性。当前仅上报状态不会使这两个视图失效。

## Decisions

1. 在现有主线程上报入口比较实际状态；发生变化时先发出 `objectWillChange`，再同步写入 FFI。无异步间隙，SwiftUI 下一轮渲染读取已更新状态。
2. 保留 Rust 作为连接状态和主机聚合的所有者，不引入 Swift 状态副本、轮询定时器或伪造页签列表变化。
3. 订阅 Combine 通知并检查真实 FFI 状态，覆盖连接成功、连接失败、退出、重连、非活动页签、同主机其他连接、SFTP 和无效回调；测试不连接真实 SSH 主机。

## 评审

本次是恢复已有行为的局部 UI 通知修复，不引入业务规则、平台分支、依赖或 FFI 修改。既有未提交的页签关闭修复及其他文件改动予以保留。重复状态不发布通知，可避免视图生命周期重复上报引起刷新循环。

## 验收

每次有效状态转换同步产生观察通知，查询返回最新页签及主机聚合状态；无需切换页签或等待其他 UI 事件。远端退出只影响对应页签。未知、已关闭页签和重复状态不产生通知。
