## Decisions

用户验收与删除授权已完成评审。直接移除不可达的旧 UI，不增加新的抽象层；默认新路径保持原样。

## 影响映射

| 范围 | 处理 | 验证 |
| --- | --- | --- |
| HostListView/WorkspaceView/AppConfig | 删除旧装配与开关 | 静态契约、双端编译 |
| 旧页签/滚动/布局/策略及其专属测试 | 删除；保留统一栏与会话测试 | 引用检索、Swift tests |
| SettingsView/WorkspaceStore | 移除失效选项与持久化读写；不清除用户历史数据 | 静态契约、Swift tests |
| 已有未提交的窗口与传输修改 | 保留 | 与编辑前备份比较 |
| Rust/FFI、会话关闭确认、统一栏 | 保持 | cargo test、Swift 回归 |

风险为中等：双端装配和测试引用受影响。UI 验收来自用户确认；编译、自动测试与覆盖率按实测记录，不能由人工验收推定。
