# 实施任务：业务下沉与薄桥收敛

本清单全部为待实施任务。此次创建规格不代表批准或完成实现；评审后按依赖顺序执行，每个实现任务以其前置测试的 red → green 记录验收。既有测试先用于建立基线，新核心 API 的测试应先因缺失能力或错误行为失败；不得为形式上的 red 破坏既有实现。

每项实施尽量控制在一次可验证提交内；如超出，按相同测试→实现顺序继续拆分。每个切片完成后同步旧路径→核心入口→FFI 适配→真实调用方→测试的迁移记录，门禁责任随该切片移动，不等到最终阶段才恢复覆盖统计。
