## Context

动机见 proposal.md。已有导航和传输测试可复用；工作区有其他未提交的标题栏改动，必须保留。此变更涉及跨语言契约及异步状态，按高风险边界验证，但不接触真实服务器。

## Goals / Non-Goals

目标：用最小共享路径规则保证列表、地址和任务路径一致。非目标见 proposal.md；不新增持久化及第三方依赖。

## Decisions

- Rust 提供绝对目录校验和子路径拼接，经同步 FFI 调用。仅移除末尾多余分隔符，不折叠 `..`，防止改变远程符号链接语义；不裁剪合法文件名空格。相对路径和 `~` 明确报错，避免服务器会话 cwd 与面板目录混用。
- Swift 导航作为展示状态：主线程隔离，一次发布目录快照；请求序号拒绝过期结果，取消不提交。进入、上级和手动跳转走同一加载流程。
- 保留现有初始目录返回入口与面包屑，新增显式编辑按钮。home 外面包屑从 `/` 展示，文件系统根不允许再向上。
- 上传扫描前保存目标目录，所有后续分支复用该快照。下载已把目标目录作为一次扫描的值参数传入，保留该行为。
- 导航器变化转发至会话观察者，确保加载与列表刷新可见；替换数据源时重建订阅。

## Risks / Trade-offs

- 绝对路径输入范围较窄 → 占位符与错误明确告知，不偷偷按本地 cwd 解析远程相对路径。
- 测试替身无法证明真实服务器权限与符号链接行为 → 保留服务器解析，不承诺真实服务器验收；不主动连接用户服务器。
- 全仓覆盖率或双端构建可能受既有代码/环境影响 → 分别记录实际结果，不能把未运行视为通过。
