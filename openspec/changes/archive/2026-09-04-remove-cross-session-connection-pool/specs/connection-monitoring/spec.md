## MODIFIED Requirements

### Requirement: 分层会话可观测性

每条传输连接记录 SHALL 独立列出 SSH 会话状态（含 keepalive 结果），以及其尚未释放或最近已结束的 shell、SFTP 与 exec 通道。每条连接 MUST 提供非敏感的所有者类型和关联标识；每个通道记录 MUST 包含通道标识、类型、状态、创建时间、最后活动时间、累计入站/出站逻辑字节数。通道关闭或失败后，记录 MUST 保留到所属连接释放或被新的内存快照策略移除为止，并显示正常结束、显式关闭或异常关闭的最终原因。shell 的本地输入写入失败或收到远端关闭时，系统 MUST 在对应终端标签页显示不可交互提示；无输出但未发生失败事件时 MUST 显示为空闲而非异常。

#### Scenario: 同一主机的独立所有者连接

- **GIVEN** 同一主机有一个终端标签和一个 SFTP 标签
- **WHEN** 用户查看连接监控详情
- **THEN** 页面显示两条底层连接，并分别显示终端与 SFTP 的非敏感所有者关联，MUST NOT 合并为一条连接

#### Scenario: 终端输入失败

- **GIVEN** 终端 shell 的底层通道已经关闭或向其写入数据返回错误
- **WHEN** 用户尝试输入
- **THEN** 终端标签页立即显示该会话不可交互及可区分的失败状态，且连接监控页同步显示对应 Socket、SSH 会话和通道的已知状态

#### Scenario: shell 正常结束

- **WHEN** 用户输入 `exit` 且远端 shell 正常关闭 Channel
- **THEN** 监控将该所有者连接标记为正常结束或显式释放，MUST NOT 将同主机其他连接标记为关闭
