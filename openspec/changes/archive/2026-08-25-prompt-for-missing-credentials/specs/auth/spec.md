## ADDED Requirements

### Requirement: 缺失凭据提示

系统 MUST 将缺少密码或私钥口令识别为可恢复的凭据输入状态，而非连接超时。终端与 SFTP 的行为 MUST 一致；用户输入的凭据仅在当前标签页会话中有效。

#### Scenario: 未保存密码时提示输入

- **GIVEN** 密码认证主机没有可读取的已保存密码
- **WHEN** 用户打开终端或 SFTP 标签
- **THEN** 系统显示密码输入窗口，且不显示连接超时页

#### Scenario: 已保存密码不可读取

- **GIVEN** 密码认证主机标记为已保存密码但对应凭据不可读取
- **WHEN** 用户打开终端或 SFTP 标签
- **THEN** 系统显示密码输入窗口，并允许用户为当前标签页输入密码

#### Scenario: 缺失私钥口令时提示输入

- **GIVEN** 私钥认证需要口令且已保存口令不可读取
- **WHEN** 用户打开终端或 SFTP 标签
- **THEN** 系统显示私钥口令输入窗口，且不将该情况显示为连接超时

#### Scenario: 输入后重试

- **WHEN** 用户在凭据输入窗口提交非空凭据
- **THEN** 系统使用该凭据仅为当前标签页重新发起连接
