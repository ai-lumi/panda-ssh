## MODIFIED Requirements

### Requirement: 标签页会话关联

每个标签页 SHALL 基于一台已保存的主机建立会话。关闭某主机的最后一个标签页时，该主机的 SSH 连接 SHALL 被显式断开；但若该主机仍存在活跃传输任务（queued / running / paused），断开 SHALL 被推迟，直到最后一个活跃传输任务进入终态后再断开。远端 shell 正常退出或关闭时，终端标签 SHALL 在呈现退出前已接收的全部输出后更新为断开状态并释放该 shell 会话；若该主机没有其他连接中或已连接的标签页且无活跃传输任务，系统 SHALL 显式断开该主机的 SSH 连接。

#### Scenario: 标签页基于已保存主机打开

- **WHEN** 用户从主机列表选择一台主机打开标签页
- **THEN** 该标签页使用该主机的地址、端口、用户名与认证方式建立会话

#### Scenario: 关闭最后一个标签页立即断开

- **GIVEN** 某主机只有一个标签页且无活跃传输任务
- **WHEN** 用户关闭该标签页
- **THEN** 该主机的 SSH 连接被立即断开

#### Scenario: 关闭 SFTP 标签页时存在活跃传输则推迟断开

- **GIVEN** 某主机的最后一个标签页为 SFTP 标签页，且该主机仍有 running 状态的传输任务
- **WHEN** 用户关闭该 SFTP 标签页
- **THEN** 传输任务继续运行，SSH 连接此时 MUST NOT 被断开
- **AND** 当该主机的最后一个活跃传输任务进入终态后，SSH 连接被自动断开

#### Scenario: 终端 shell 正常退出

- **GIVEN** 某终端标签已连接且远端 shell 在输出结束信息后正常退出
- **WHEN** 客户端读完退出前产生的全部输出
- **THEN** 该标签显示断开状态，且关闭标签时不再被视为已连接会话

#### Scenario: 退出的是最后一个主机会话

- **GIVEN** 某主机只有一个已连接终端标签，且无连接中或已连接的其他标签页与活跃传输任务
- **WHEN** 该终端 shell 正常退出
- **THEN** 系统释放 shell 会话并断开该主机的 SSH 连接

#### Scenario: 同主机仍有会话或传输

- **GIVEN** 某终端 shell 正常退出，但同主机仍有连接中或已连接的标签页，或仍有活跃传输任务
- **WHEN** 客户端处理该终端退出
- **THEN** 系统 MUST NOT 断开该主机的共享 SSH 连接
