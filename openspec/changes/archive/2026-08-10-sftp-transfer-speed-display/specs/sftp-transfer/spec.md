## ADDED Requirements

### Requirement: 文件传输进度包含速度指标

文件传输的进度展示 SHALL 包含实时速度与总速度信息，使调用方（UI）能够向用户呈现当前传输速率。速度信息可由调用方根据进度回调的时间戳与已传字节数推导，不强制要求核心库额外暴露速度字段。

#### Scenario: 上传进度可推导出速度

- **GIVEN** 上传任务持续接收进度回调（已传字节 + 时间戳）
- **WHEN** UI 根据回调计算速度
- **THEN** 可得到实时速度与总速度，并在面板中展示

#### Scenario: 下载进度可推导出速度

- **GIVEN** 下载任务持续接收进度回调（已传字节 + 时间戳）
- **WHEN** UI 根据回调计算速度
- **THEN** 可得到实时速度与总速度，并在面板中展示
