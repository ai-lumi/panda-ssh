## Why

随着服务器数量增长，扁平的单一主机列表难以维护。用户需要按用途、环境、项目等维度对服务器进行组织。分组与子分组（树形结构）是管理大量主机的标准方式，能显著降低查找与批量操作成本。

## What Changes

- 主机列表支持分组与任意层级子分组，以树形结构呈现。
- 支持分组的创建、重命名、移动（含子分组）、删除。
- 每台主机可归属一个分组，且可移动到其它分组或根级。
- 分组数据持久化，与主机配置共存于同一配置目录，跨设备同步。
- 删除分组时其下主机移至根级，不静默丢失。

## Non-Goals

- 本变更不实现分组的拖拽排序与自定义顺序持久化（按名称排序即可）。
- 本变更不实现基于分组的批量连接、批量命令等批量操作。
- 本变更不实现分组级权限、共享、协作。
- 本变更不改变主机/认证相关行为（属于 `server-management`、`authentication` 变更）。

## Capabilities

### New Capabilities

- `groups`: 服务器分组与子分组管理，含树形持久化与主机归属关系。

### Modified Capabilities

None.

## Impact

- macOS 与 iPadOS 双端：分组树 UI 为共享 SwiftUI 源码；iPadOS 上分组树与主机列表需在同一侧栏可折叠展示。
- Rust 核心（`crates/panda-core`）：主机配置模型新增分组字段；新增分组存储（分组树读写、原子写入）。
- FFI（`crates/panda-ffi`）：新增分组 CRUD 与主机归属读取/更新的同步导出函数；`HostConfigRecord` 增加分组字段。
- Swift UI：侧栏分组树、分组编辑、主机移动分组交互。
- 测试：core 侧分组树的增删改、嵌套、持久化单元测试；Swift 侧分组树状态测试。
