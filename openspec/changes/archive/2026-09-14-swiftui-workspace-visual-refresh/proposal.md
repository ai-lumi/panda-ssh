## Why

当前工作区已经具备侧栏、会话页签、终端与 SFTP 等完整结构，但视觉层级偏弱，macOS 与 iPadOS 仍共享了部分不适合触控或紧凑宽度的桌面布局。用户希望保留专业 SSH 工具的高密度工作台结构，同时使用 SwiftUI 原生组件、语义色与平台自适应布局，形成更美观且可维护的双端界面。

## What Changes

- 统一工作区信息架构为「主机侧栏 + 会话页签栏 + 活动内容区」：保留高信息密度，不把终端、SFTP 或主机信息包装成占用大量空间的装饰性卡片。
- 建立 SwiftUI 原生视觉规则：使用系统窗口控件、SF Symbols、语义背景/材质、系统分隔线与单一强调色；连接状态同时使用颜色、图标或文字表达，MUST NOT 仅依赖颜色。
- 重整侧栏顶部操作层级：新增操作为主要入口，编辑、移动、删除等选择相关操作降低视觉权重；macOS 保留系统红绿灯与 macOS 26 所需的系统工具栏，MUST NOT 仿造窗口控制按钮。
- 隐藏无信息价值的应用名称窗口标题：macOS 使用不显示标题文字的统一紧凑系统工具栏，并把会话页签作为单一的主要工具栏内容放入原标题位置；MUST NOT 在标题区显示「Panda SSH」或在内容区重复绘制第二条页签栏。
- 修正 macOS 标题区的系统控件层级：侧栏可见时只保留侧栏内部的收起入口，MUST NOT 同时显示 `NavigationSplitView` 默认侧栏按钮；侧栏隐藏时仍由系统按钮提供恢复入口。macOS 26 的主要页签项 MUST NOT 被连续的大面积共享玻璃胶囊包裹。
- 调整会话页签：macOS 标题位置的页签使用紧凑桌面尺寸并保留内部滚动/多行溢出能力；iPadOS 不显示应用名称标题，使用可触控尺寸，当前页签的关闭入口保持可发现，长按菜单继续可用。
- 补齐 macOS 页签溢出交互：滚动模式下必须支持固定的左右翻页入口、触控板水平滚动与鼠标纵向滚轮转横向滚动；新建或选择视口外页签时自动滚入可见区域，首尾位置不得产生空白越界。
- 移除终端内容顶部重复的持久主机/状态横条；主机身份与连接状态继续由会话页签以及连接中、失败或终端内容本身表达，使活动内容紧接系统工具栏并获得更多垂直空间。
- 增加响应式 iPadOS 工作区：常规宽度显示侧栏与内容区；紧凑分屏宽度允许侧栏折叠为系统导航入口，SFTP 从双栏切换为「本地 / 远程」单栏分段视图，传输任务使用适合触控的 sheet/inspector 展示。
- 修正工作区空态的操作语义：存在已保存主机时提供「选择主机」与「添加主机」，不存在已保存主机时仅突出「添加主机」；空态操作 MUST NOT 静默连接列表第一台主机。
- 保持侧栏选中与详情语义一致：用户选择主机后必须能识别该主机详情与当前活动会话的区别，MUST NOT 以无提示的侧栏高亮指向另一台主机、右侧却继续表现为该主机详情。
- 移除工作区内破坏完成度的临时视觉标记，例如已可用的「代码片段」入口上的「规划中」徽标。
- 为 Mac 常规窗口、iPad 横屏常规宽度、iPad 紧凑分屏三种尺寸建立可评审界面稿与布局验收用例。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `workspace`: 修改主窗口视觉层级、空态操作语义、页签触控可发现性、侧栏与活动内容的选择语义，以及 SFTP/传输面板在 iPadOS 紧凑宽度下的自适应布局要求。

## Impact

- **SwiftUI 源码**：主要影响 `HostListView.swift`、`SidebarView.swift`、`HostDetailView.swift`、`WorkspaceView.swift`、`WorkspaceTabBar.swift`、`WorkspaceTabButton.swift`、`HorizontalWheelScrollView.swift`、`TerminalTabView.swift`、`SftpTabView.swift` 与 `TransferPanelView.swift`。
- **macOS**：保持系统工具栏和系统窗口控件，隐藏窗口标题文字并将 `WorkspaceTabBar` 移入系统工具栏主要位置；重整侧栏工具区、空态和内容层级，不回退已归档的 macOS 26 标题栏融合策略。
- **iPadOS**：保留 `NavigationSplitView`，不使用应用名称作为导航标题；新增常规宽度与紧凑分屏布局差异，扩大触控目标并提高页签关闭入口可发现性。
- **测试**：新增 Swift/XCTest 可测布局策略、页签可见状态、空态动作路由与选择状态测试；纯像素布局通过 Preview/截图人工验收。
- **Rust/FFI**：不修改 `panda-core`、`panda-ffi`、SSH/SFTP 协议行为或凭据存储契约；不新增第三方 UI 依赖。

## Non-goals

- 不修改 SSH 连接、主机密钥校验、SFTP 文件操作、传输调度或连接池等业务规则。
- 不更换 SwiftTerm，不重新设计终端 ANSI 配色、字体渲染或键鼠协议。
- 不增加 iPhone 目标，不为未来 Linux 客户端规定具体 UI。
- 不在本变更中重做主机编辑表单校验、配置导入导出错误处理或全局 Toast 体系；这些交互问题另立提案。
- 不引入自绘窗口红绿灯、自定义跨平台控件库、WebView 或第三方页签组件。
- 不完全移除 macOS 系统标题栏/工具栏，不以内容侵入方式自行承担红绿灯避让、窗口拖拽、全屏和侧栏恢复行为。
- 不追求 macOS 与 iPadOS 像素级一致；两端共享信息架构和状态语义，布局与触控尺寸遵循各自平台习惯。
