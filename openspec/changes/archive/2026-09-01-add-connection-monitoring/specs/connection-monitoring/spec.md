## Purpose

为用户提供仅覆盖 Panda SSH 自身连接的可验证运行时视图，以传输 I/O、SSH keepalive、通道事件和终端交互状态识别连接异常，并展示 Socket I/O 流量，同时保护凭据与会话内容。

## ADDED Requirements

### Requirement: 连接监控快照

系统 SHALL 提供当前由 Panda SSH 建立且尚未释放的每条传输连接的内存快照。每条记录 MUST 包含稳定的连接标识、主机标识与地址端口、建立时间、传输 I/O 状态、最近 Socket I/O 时间与错误、累计 Socket 入站/出站字节数和当前入站/出站速率。传输 I/O 状态 MUST 依据实际建连结果、读/写结果、EOF 与超时更新，MUST NOT 依据无业务流量推断异常。平台可获取的内核 TCP 状态 SHALL 作为可选附加字段。快照 SHALL 明确其字节数为应用在 Socket 读写边界可观测的 SSH 加密载荷字节，而非 TCP/IP 头或重传的线缆级流量。

#### Scenario: 多连接分别展示
- **GIVEN** 应用已对两台不同主机建立 SSH 连接
- **WHEN** 用户打开或刷新连接监控页面
- **THEN** 页面显示两条互不合并的连接记录，且每条记录具有各自的主机、状态和流量计数

#### Scenario: 无活动连接
- **GIVEN** 应用当前没有存活的 SSH 连接
- **WHEN** 用户打开连接监控页面
- **THEN** 页面显示空状态，且 MUST NOT 为填充页面而建立新连接

### Requirement: 分层会话可观测性

每条传输连接记录 SHALL 独立列出 SSH 会话状态（含 keepalive 结果），以及其尚未释放或最近已结束的 shell、SFTP 与 exec 通道。每个通道记录 MUST 包含通道标识、类型、状态、创建时间、最后活动时间、累计入站/出站逻辑字节数；存在工作区标签页或传输任务关联时 SHALL 提供非敏感关联标识。通道关闭或失败后，记录 MUST 保留到所属连接释放或被新的内存快照策略移除为止，并显示最终状态。shell 的本地输入写入失败或收到远端关闭时，系统 MUST 在对应终端标签页显示不可交互提示；无输出但未发生失败事件时 MUST 显示为空闲而非异常。

#### Scenario: shell 与 SFTP 共享连接
- **GIVEN** 同一 SSH 连接同时承载一个 shell 与一个 SFTP 会话
- **WHEN** 用户查看该连接详情
- **THEN** 页面分别显示两个通道及其类型、状态和各自逻辑流量，MUST NOT 将其伪报为两条底层连接

#### Scenario: 终端输入失败
- **GIVEN** 终端 shell 的底层通道已经关闭或向其写入数据返回错误
- **WHEN** 用户尝试输入
- **THEN** 终端标签页立即显示该会话不可交互及可区分的失败状态，且连接监控页同步显示对应 Socket、SSH 会话和通道的已知状态

### Requirement: 按需健康检查

系统 SHALL 仅对已建立且未释放的 SSH 连接提供用户触发的健康检查。检查结果 MUST 为健康、不可用或未知之一，并包含无敏感数据的最近检查时间与失败摘要。健康检查 MUST NOT 建立新连接、自动重连、修改主机配置或访问凭据。

#### Scenario: 健康连接检查
- **GIVEN** 一条仍可打开 SSH 通道的已建立连接
- **WHEN** 用户对该连接触发健康检查
- **THEN** 检查结果为健康，并更新该连接的最近检查时间

#### Scenario: 已失效连接检查
- **GIVEN** 一条因远端关闭而不可再打开通道的已建立连接
- **WHEN** 用户对该连接触发健康检查
- **THEN** 检查结果为不可用并包含失败摘要，且系统 MUST NOT 自动建立替代连接

### Requirement: 遥测隐私边界

连接监控记录、页面与相关日志 MUST NOT 包含或持久化密码、私钥、私钥口令、命令文本、终端输出、文件内容或完整本地私钥路径。监控数据 SHALL 默认为仅内存状态，应用重启后 MUST NOT 恢复此前连接或流量记录。

#### Scenario: 敏感终端内容不出现在监控中
- **GIVEN** 用户在 shell 中输入含敏感文本的命令并收到输出
- **WHEN** 用户查看连接监控页面或其相关运行时日志
- **THEN** 记录仅包含计数字段与允许的状态摘要，且 MUST NOT 包含命令或输出文本
