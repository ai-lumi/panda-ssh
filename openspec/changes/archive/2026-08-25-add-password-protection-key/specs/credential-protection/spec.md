## Purpose

本地凭据保护能力让用户在不依赖系统钥匙串的前提下，将 SSH 密码与私钥口令保存在配置目录，并可选择以用户设置的保护密钥加密保存。

## ADDED Requirements

### Requirement: 可选保护密钥

系统 SHALL 允许用户设置、变更或移除密码保护密钥。保护密钥 MUST NOT 写入配置文件、凭据文件、日志或导出归档；设置页 MUST 在未设置保护密钥时明确提示已保存凭据将以明文存储。

#### Scenario: 设置保护密钥

- **WHEN** 用户输入并确认有效的保护密钥
- **THEN** 系统在不持久化该密钥的前提下，将已保存凭据转换为受保护格式

#### Scenario: 未设置保护密钥

- **WHEN** 用户保存凭据且未设置保护密钥
- **THEN** 系统将凭据以兼容的明文格式保存，并展示明文存储提示

#### Scenario: 移除保护密钥

- **GIVEN** 本地凭据处于受保护格式
- **WHEN** 用户提供正确的现有保护密钥并确认移除
- **THEN** 系统将凭据转换为明文格式，且之后不再要求保护密钥

### Requirement: 加密凭据的完整性与可恢复错误

受保护凭据 MUST 使用每个凭据文件唯一的随机盐、基于保护密钥的派生密钥和带认证的加密格式。系统 MUST 在解密、认证或格式验证失败时拒绝返回凭据，并向用户提示凭据无法解锁；MUST NOT 将该错误伪装成密码为空、认证失败或网络超时。

#### Scenario: 正确密钥读取凭据

- **GIVEN** 凭据文件已受保护且用户已提供正确保护密钥
- **WHEN** 用户连接使用已保存凭据的主机
- **THEN** 系统读取原始凭据并用于该连接

#### Scenario: 错误保护密钥

- **GIVEN** 凭据文件已受保护
- **WHEN** 用户提供错误保护密钥
- **THEN** 系统拒绝读取或修改凭据，并显示可区分的解锁失败提示

#### Scenario: 凭据文件被篡改

- **GIVEN** 凭据文件已受保护
- **WHEN** 系统检测到认证标签或格式校验失败
- **THEN** 系统不返回任何凭据，且不覆盖原文件

### Requirement: 明文凭据兼容与原子迁移

系统 MUST 继续读取既有明文凭据记录。设置、变更或移除保护密钥时，凭据文件 MUST 原子重写；重写失败时原文件 MUST 保持可读，且保护状态不得误报成功。

#### Scenario: 读取既有明文凭据

- **GIVEN** 用户升级前保存了明文凭据
- **WHEN** 用户未设置保护密钥并连接对应主机
- **THEN** 系统读取该明文凭据并保持可连接

#### Scenario: 迁移写入中断

- **GIVEN** 系统正在将明文凭据转换为受保护格式
- **WHEN** 原子替换前发生写入错误
- **THEN** 原凭据文件仍可读取，且设置页显示迁移失败
