## MODIFIED Requirements

### Requirement: 连接失败提示

标签页在建立会话失败或远端 shell 结束时 SHALL 在标签页完整内容区展示可区分的错误信息，且 MUST NOT 导致 App 崩溃或影响其它标签页。失败页 MUST 提供「重试」或「关闭」操作，并在窗口缩放或侧栏显示状态变化时保持在内容区可用矩形中。

#### Scenario: 连接失败展示错误

- **GIVEN** 服务器不可达或认证失败
- **WHEN** 用户从该主机打开标签页
- **THEN** 标签页内容区显示失败原因，并提供「重试」或「关闭」操作

#### Scenario: 已连接后远端 shell 结束

- **GIVEN** 一个已连接的终端标签
- **WHEN** 远端 shell 正常结束或发生传输错误
- **THEN** 该标签内容区显示不可交互的最终状态与重试或关闭操作，其他标签页保持不变
